# Generated course overlays

**Do not hand-edit anything in this folder.** These files are built from
`routes/breck-epic-2026.json` (the official Breck Epic 2026 CalTopo export)
by the build step described in DECISIONS.md.

The source file is 4.7 MB — far too large to serve to a phone on trailhead
LTE. The build simplifies each stage line and writes small per-stage GeoJSON
here.

A missing file is not an error. That stage simply won't draw an underlay.
